# OttenSeiwald-TimeTracking

US-01 | Must 
As a user, I want to identify myself using my personal ID so that my time is assigned to me.

US-02 | Must 
As a user, I want to select a project and describe my task so that my work is documented correctly.

US-03 | Must 
As a user, I want to start and stop a timer so that I can record time with minimal effort.

US-04 | Must 
As a user, I want to enter working hours manually so that I can record past or missed work.

US-05 | Must 
As a project manager, I want time entries to be saved in a database so that records persist after closing the application.

US-06 | Must 
As an administrator, I want to assign people to roles and define hourly rates so that costs can be calculated consistently.

US-07 | Must 
As a project manager, I want the system to calculate costs for each time entry so that billable amounts are accurate.

US-08 | Must
As a project manager, I want to see total hours and costs per project and person so that I can monitor project effort.

US-09 | Must
As a project manager, I want to generate an invoice per project so that customers can be billed without manual calculations.

US-10 | Must
As a customer, I want invoices to list activities, hours, hourly rates and totals so that charges are transparent.

US-11 | Must
As a developer, I want automated unit tests for duration, rates and invoice totals so that calculation errors are detected early.

US-12 | Must 
As a manager, I want charts showing project hours and costs so that I can compare projects visually.

US-13 | Should 
As a manager, I want to see the cost distribution by role so that I can understand where project expenses originate.

US-14 | Could 
As a manager, I want to define a project budget and receive a warning when 80% is used so that I can prevent overspending.

US-15 | Could 
As an employee, I want to distinguish billable and non-billable activities so that internal work is not charged to customers.

US-16 | Could 
As a project manager, I want to export invoices as PDF and time entries as Excel so that I can share and archive records.
